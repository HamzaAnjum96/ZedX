How it works

From one-off requests to a steady flow

  1. Set up a workstream for each function

    Staff onboarding, IT requests, estates jobs, policy approvals: each part of the organisation gets a workflow of its own.

  2. Put its tasks on a Kanban board

    Every task sits in a column showing its stage, so the state of the work is clear at a glance.

  3. Work the board together

    Add tasks as they come in and move them on as they progress. Colleagues and outside partners with guest logins work on the same board.

  4. Keep leaders informed

    Link a project's workstream to Project Portfolios and its progress is summarised in structured updates. Export to Excel whenever someone needs a list.

Why Kanban

Why a board suits operational work

Operational work rarely fits a two-week plan. It arrives when it arrives. A Kanban board handles that well.

See the whole flow

Every request is on the board, so nobody has to ask where something has got to.

Spot where work waits

When cards pile up in one column, the bottleneck is visible and the team can act on it.

Finish before starting more

Teams pull new work in when they have room, instead of juggling everything at once.

Works alongside

Agile Sprints

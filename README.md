# ZedX: Group WorkStreams & Agile Sprints brochure

A GitHub Pages brochure site for the two board-based apps on the
[ZedX Apps Platform](https://www.zedxapps.com/index.html):

- **Group WorkStreams**: Kanban workflows, one for each function in an organisation.
- **Agile Sprints**: Scrum delivery with epics, stories, sprints, releases and stand-up reporting.

Work in progress. The site will be in `docs/`, and the research and planning
behind it in `replica/`.

## How it is built

The site is planned and built with the
[Replica skill pack](https://github.com/Jakeschincariol/replica-skill)
(MIT), installed project-locally in `.claude/skills/`.
